# UPDATE 0.0.2 - WOOD STONE DISTRICT

**Goal:** Build the first playable district.

**Release Result:** Players can explore the first real part of Golden Z World.

---

## Overview

Wood Stone is the starting district and the safest zone in the game. It serves as the tutorial area and safe haven for new players.

**Zone Properties:**
- 🟢 Safety Level: GREEN (Safe/Protected)
- Size: 500x500 studs
- PvP: Disabled
- Crime: Disabled
- NPCs: Bank tellers, store clerks, security guards

### STEP 2: Create Base Terrain

Create a script to generate the basic terrain: **ServerScriptService/Systems/TerrainGenerator.lua**

```lua
local TerrainGenerator = {}
local Terrain = workspace.Terrain

function TerrainGenerator:GenerateWoodStone()
	-- Create base ground (100x100 studs, 10 studs tall)
	Terrain:FillBall(Vector3.new(0, 5, 0), 250, Enum.Material.Grass)
	
	-- Create road (straight line through center)
	Terrain:FillRegion3(Region3.new(Vector3.new(-10, 5, -250), Vector3.new(10, 6, 250)), 4, Enum.Material.Concrete)
	
	-- Create perimeter walls (invisible barriers for zone boundaries)
	local wallSize = 10
	local wallHeight = 50
	local zoneSize = 500
	
	-- North wall
	Terrain:FillRegion3(Region3.new(Vector3.new(-zoneSize/2, 0, zoneSize/2), Vector3.new(zoneSize/2, wallHeight, zoneSize/2 + wallSize)), 4, Enum.Material.Rock)
	-- South wall
	Terrain:FillRegion3(Region3.new(Vector3.new(-zoneSize/2, 0, -zoneSize/2 - wallSize), Vector3.new(zoneSize/2, wallHeight, -zoneSize/2)), 4, Enum.Material.Rock)
	-- East wall
	Terrain:FillRegion3(Region3.new(Vector3.new(zoneSize/2, 0, -zoneSize/2), Vector3.new(zoneSize/2 + wallSize, wallHeight, zoneSize/2)), 4, Enum.Material.Rock)
	-- West wall
	Terrain:FillRegion3(Region3.new(Vector3.new(-zoneSize/2 - wallSize, 0, -zoneSize/2), Vector3.new(-zoneSize/2, wallHeight, zoneSize/2)), 4, Enum.Material.Rock)
end

return TerrainGenerator
```

Call this in a server script:
```lua
local TerrainGenerator = require(game.ServerScriptService.Systems.TerrainGenerator)
TerrainGenerator:GenerateWoodStone()
```

### STEP 10: Create Zone Entry/Exit System

**Script:** `ServerScriptService/Systems/ZoneManager.lua`

```lua
local ZoneManager = {}
local Players = game:GetService("Players")
local DataService = require(game.ServerScriptService.Services.DataService)

-- Detect zone changes
local zoneCheckInterval = 1 -- Check every 1 second

function ZoneManager:GetPlayerZone(character)
	if not character or not character:FindFirstChild("HumanoidRootPart") then
		return nil
	end
	
	local position = character.HumanoidRootPart.Position
	
	-- Check which zone the player is in
	-- Zone boundaries are at specific X coordinates
	if position.X < 250 then
		return "WoodStone"
	elseif position.X < 750 then
		return "Downtown"
	elseif position.X < 1350 then
		return "VoidDistrict"
	elseif position.X < 1950 then
		return "GoldenCoast"
	else
		return "BlackZone"
	end
end

function ZoneManager:OnPlayerZoneChange(player, oldZone, newZone)
	local playerData = DataService:GetPlayerData(player.UserId)
	if not playerData then return end
	
	playerData.CurrentZone = newZone
	
	-- Show zone message to player
	print(player.Name .. " entered " .. newZone)
	
	-- TODO: Show visual notification to player
	-- TODO: Check if crime is allowed in new zone
	-- TODO: Update player reputation based on zone
end

-- Main loop
spawn(function()
	while true do
		wait(zoneCheckInterval)
		
		for _, player in pairs(Players:GetPlayers()) do
			if player.Character then
				local currentZone = ZoneManager:GetPlayerZone(player.Character)
				local playerData = DataService:GetPlayerData(player.UserId)
				
				if playerData and currentZone and playerData.CurrentZone ~= currentZone then
					ZoneManager:OnPlayerZoneChange(player, playerData.CurrentZone, currentZone)
				end
			end
		end
	end
end)

return ZoneManager
```
