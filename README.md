## Project Overview

**Golden Z World** is a complex Roblox MMO featuring:
- Multi-district open world (5 zones with different risk levels)
- Player-driven economy with trading and auctions
- Multiple career paths (Police, Bounty Hunters, Criminals, Business Owners, Content Creators)
- Property ownership and customization
- Vehicle collection and racing
- Event systems (Mega Jewelry, Yacht Robbery)
- Advanced security and anti-exploit systems
- Social features (followers, posts, leaderboards)

**Target: 100+ hours of gameplay progression**
